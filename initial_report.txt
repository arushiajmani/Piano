1. Introduction to the Project
A virtual piano is a software application that reproduces the keys and sound of a piano on a computer screen, allowing a user to play music without a physical instrument. As a browser-based application it requires no installation or special hardware, which makes it convenient for students and beginners. Aligned with the PD4 theme of Music, IoT, Robotics and Smart Systems, this project treats the virtual piano as an interactive musical instrument whose input devices are the mouse and the keyboard.
The project is developed using HTML, CSS and JavaScript and is based on an existing open-source implementation (SABER-MOHAMED/Piano). The current version presents seventeen keys, ten white and seven black, covering the notes from C to the E of the following octave. Each key is linked to a stored audio file, and the page displays the note name and keyboard shortcut for each key.
2. Objectives
The main objectives are: (i) to provide an accessible virtual piano that runs in a standard web browser without installation; (ii) to enable interactive music practice through immediate audio response to mouse and keyboard actions; and (iii) to create a simple, user-friendly musical interface in which note names and keyboard controls are clearly visible. Technically, the project also demonstrates the use of event handling and Document Object Model (DOM) manipulation in JavaScript.
3. Input Parameters
The application accepts the following inputs: mouse clicks on the on-screen piano keys; keyboard key presses, where the white keys are mapped to A, S, D, F, G, H, J, K, L and the semicolon key, and the black keys to W, E, T, Y, U, O and P; and mouse hovering over the piano, which displays hints. No other input devices are used in the current implementation.
4. Output
When a key is clicked or pressed, the application plays the audio file of the corresponding note. The interface supports the user visually by showing the note name and keyboard control on each key when the piano is hovered, and the page layout includes a note display area beneath the keyboard. The system plays stored sound files only; it does not record performances or perform any audio processing.
5. Applications
The application can be used for beginner music learning, where students identify notes by name and sound; for basic musical exploration, where users experiment with simple melodies; and for keyboard familiarisation, where learners understand the arrangement of white and black keys. Because it runs in a web browser, it also supports accessible, no-cost music practice in classrooms, laboratories or at home.
6. Future Scope (Proposed Enhancements)
The following improvements are proposed and are not part of the current implementation: support for Indian classical music through Carnatic swara labels (Sa, Ri, Ga, Ma, Pa, Da, Ni) alongside the existing note names; customisable keyboard mappings; a metronome; recording and playback of user performances; and beginner practice exercises. To move further towards the PD4 theme, the system could later be extended with an automatic rhythm accompaniment, and with input from external devices such as a MIDI keyboard or sensor-based controls.
